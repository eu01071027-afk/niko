# 🐱 Niko — 傲娇黑猫的每日塔罗

一只叫 Niko 的傲娇黑猫少年，每天帮你抽三张塔罗牌，做你的情感陪伴和日常管理。

## 使用方式

1. 打开 `index.html`（双击即可，无需安装任何东西）
2. 输入邀请码进入
3. 从扇形牌堆中选 3 张牌
4. 翻牌后 AI 生成运势解读 + 衣食住行建议
5. 填写今天做了什么，Niko 给你傲娇回应
6. 每天只能抽一次，零点重置

## 技术

- 纯 HTML + CSS + JS，零框架零依赖
- 数据存储在浏览器 localStorage
- AI 解读通过 DeepSeek API 实时生成
- 关闭 AI 后仍有完整预写内容兜底

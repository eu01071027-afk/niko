# 🐱 Niko — 傲娇黑猫的每日塔罗

一只穿深紫色斗篷、挂月亮石的傲娇黑猫塔罗占卜师，每天陪你抽牌、聊天、记录生活。

---

## 功能

**🔮 每日塔罗**
每天零点后抽三张牌——心境、挑战、指引。78 张 Rider-Waite-Smith 塔罗牌，AI 实时解读运势，给出衣食住行建议。

**💬 自由聊天**
随时和 Niko 聊天。Niko 会根据七日行为和心情记忆回应你，好感度越高态度越软。

**💜 好感度系统**
抽牌、填写行为记录、完成任务、陪伴专注、戳 Niko 都会累积好感度。好感度分三个关系阶段（初识/半心/深心），Niko 的语气会随阶段真实变化。

**⏳ 陪伴模式**
设定专注时长，Niko 陪你倒计时。沙漏动画、中途提醒、到时叮声。进行中锁定界面防止分心，随时可提前结束。

**📋 长期任务**
设定需要多天完成的任务，每天签到推进度。Niko 会根据当天塔罗结果鼓励或督促你。

**📝 行为记录**
抽完牌后记录衣/食/住/行的实际行动，Niko 逐条傲娇点评。同行的七日观察卡片会根据近期数据给你一个小洞察。

**💭 心情追踪**
每天记录心情，Niko 根据好感度阶段给出不同的回应。

**📖 记忆之书**
你和 Niko 一起走了多远——第一次遇见、抽牌天数、收集里程碑、陪伴次数……所有值得记住的时刻都在这里。

**🌤 天气提醒**
浏览器 GPS / IP 自动定位，Niko 提醒你当天天气和注意事项。

**🃏 塔罗图鉴**
抽到的牌自动解锁，78 张全收集触发 Niko 的特殊反应。

## 使用方式

双击 `index.html` 直接在浏览器打开，无需安装任何东西。

或访问线上版：**[eu01071027-afk.github.io/niko](https://eu01071027-afk.github.io/niko/)**

---

## 技术

- 纯 HTML + CSS + JS，零框架零依赖
- 数据存储在浏览器 localStorage
- AI 通过 DeepSeek API 实时生成（可关闭，有完整预写内容兜底）
- 天气通过 Open-Meteo 免费 API + 浏览器 GPS / IP 定位
- 桌面端优先设计
